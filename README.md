# brainnet3d

Interactive 3-D brain network plots and graph-theory metrics for connectivity matrices.

This package is in early development. The API may change, and documentation is in preparation.

## Installation

Clone this repository, then from its root:

```bash
pip install .
pip install ".[graph]"   # adds graph-theory metrics
pip install ".[atlas]"   # adds atlas and surface templates, downloaded on first use
pip install ".[html]"    # adds export of 3-D figures as interactive HTML pages
```
